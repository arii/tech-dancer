## Problem Statement

Repeated Tailwind utility strings (like `transition-all duration-200`, `active:scale-[0.98]`, and typography classes) are scattered across multiple UI components and variant definitions without utilizing underlying layout primitives.

## Goal

To centralize shared compositional constants (e.g., `transitions`, `interaction`, `typography`) into `src/styles/utilities.ts` to improve maintainability and consistency in UI components and layout primitives.

## Non-Goals

We are not redesigning component states or introducing new color/spacing tokens; this is purely a refactoring to DRY up shared Tailwind utility strings.

---

## Proposed Approach

1.  **Create Utility Constants**: Create `src/styles/utilities.ts` and export the following constants:
    *   `transitions`: `{ all: "transition-all duration-200", colors: "transition-colors duration-200", transform: "transition-transform duration-200", slow: "transition-all duration-300" }`
    *   `interaction`: `{ disabled: "disabled:opacity-50 disabled:cursor-not-allowed", activeScale: "active:scale-active", hover: "hover:bg-line/10", accentHover: "hover:border-accent cursor-pointer", ghost: "hover:bg-line/10 text-text-dim hover:text-text-main" }`
    *   `typography`: `{ label: "text-sm font-bold tracking-wide", tag: "font-semibold uppercase tracking-wider" }`
2.  **Define Custom Utility**: In `src/styles/tokens.css`, add `--raw-scale-active: 0.98;` and in `src/index.css`, create a custom `@utility scale-active` that uses this token and includes `@media (prefers-reduced-motion: reduce) { transform: none !important; }`.
3.  **Refactor Variants**: In `src/lib/variants.ts`, import these constants and `cn`. Refactor the string literals in `buttonVariants`, `actionButtonVariants`, `cardVariants`, `filterButtonVariants`, `tagVariants`, `journalVariants`, and `listRowVariants` to compose these constants using `cn()`. Ensure that these updated variants integrate properly with layout primitives (like `Box`, `Stack`) when consumed in components.
