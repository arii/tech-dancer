BoomTick.blog — West Coast Swing Lifestyle Blog
Overview
A specialized lifestyle and technology platform for the West Coast Swing (WCS) dance community. Combines a content-driven blog with data-intensive features like competition analysis tools and a "UX Auditor" for dancers.

Tech Stack
Frontend: React 19 + TypeScript (strict mode)
Build Tool: Vite 6
Styling: Tailwind CSS 4.0 (via @tailwindcss/vite plugin)
Routing: React Router 7 (lazy-loaded routes)
State: Zustand + TanStack Query (React Query)
Animations: Motion (Framer Motion)
Data: hyparquet (Parquet files in browser), PapaParse (CSV)
Backend Services: Firebase Firestore (UX Auditor feature)
Analytics: Vercel Analytics
Package Manager: pnpm 10+
Project Structure
/content/ — Markdown content (posts, resources, studies, events)
/src/ — React application
/features/ — Domain-specific logic (research, journal, ux-auditor)
/components/ — Shared UI components
/layouts/ — Design system primitives and layout wrappers
/lib/ — Utilities, types, content loading logic
/config/ — Routes and research tools configuration
/etl/ — Python-based pipeline for scraping/processing competition data into Parquet format
/public/ — Static assets including wcs_prelims.parquet data file
/scripts/ — Build-time utilities (sitemap generation, SPA stubs)
/dev-tools/ — Automation scripts for development
Development
Dev server: pnpm run dev — runs on port 5000, host 0.0.0.0
The dev script also copies etl/data/wcs_prelims.parquet → public/data/
Build: pnpm run build (runs type-check + vite build)
Replit Configuration
Workflow: "Start application" → pnpm run dev → port 5000 (webview)
Deployment: static site, build with pnpm run build, serve dist/
engine-strict=false in .npmrc (to work around rollup-plugin-visualizer requiring Node 22; we run Node 20)
Environment Variables
VITE_APP_URL — URL where the app is hosted (default: https://boomtick.blog)
VITE_CONTACT_FORM_ENDPOINT — Contact form API endpoint
Firebase config variables for UX Auditor (optional feature)
Key Features
