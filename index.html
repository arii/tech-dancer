Simulating the Floor: The "Zero-Gain" Phenomenon

In West Coast Swing (WCS), judges are typically clustered in the center of the room. This structural layout creates a massive blind spot. Because the panel functions as a centralized sensor cluster, they share a nearly identical Occlusion Profile.

This interactive Monte Carlo simulation visualizes how dynamic occlusion systematically excludes dancers from being judged, proving that making the cut is often more about spatial probability than pure skill. This platform serves as a live demonstration of complex system modeling and data infrastructure.

Simulation Architecture

How the high-performance simulation engine is built using NumPy vectorization and RangeLibc for elite-grade modeling.

Kinematic Foundations

WCS agents are modeled as non-static rectangular agents within linear corridors ("slots"). Kinematics are defined by periodic functions simulating 6-count and 8-count rhythmic cycles.

  • Cartesian Coordinate Mapping (0,0 center)
  • Vectorized Translation along Slot Vectors
  • Monte Carlo Sensitivity Analysis

Computational Optimization

To achieve the "Scalability" required of a professional portfolio, the engine eliminates Python loops in favor of NumPy broadcasting and matrix operations.
