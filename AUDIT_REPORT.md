### 1. src/layouts/Box.tsx
* **Location:** `src/layouts/Box.tsx` (Lines 11-200)
* **The Slop:** Massive prop-to-class mapping system that recreates much of Tailwind's functionality (padding, margin, gap, flex, etc.) as component props.
* **Why it's likely AI Drift:** This is a classic "Impeccable System" over-engineering pattern where AI tries to create a type-safe abstraction over Tailwind, resulting in a 200+ line component just to wrap a `div`. It obscures natural Tailwind usage and adds significant bundle size and runtime overhead.
* **Remediation:** Refactor layout-heavy components to use native Tailwind classes directly or a much thinner `Box` primitive that only handles essential layout constraints without mapping every single CSS property.

### 2. src/lib/style-utils.ts
* **Location:** `src/lib/style-utils.ts` (Lines 8-63)

* **Why it's likely AI Drift:** AI often hallucinations the need for manual JIT resolution logic when Tailwind's compiler handles this natively. This logic is brittle and adds unnecessary complexity to the styling pipeline.
* **Remediation:** Remove manual JIT parsing. Use standard Tailwind classes or CSS variables for dynamic values.
