# APPROVEDLIST.md

This file contains the approved terminology and phrasing for BoomTick.Blog.
Use these terms to maintain a consistent voice that resonates with the West Coast Swing (WCS) community.

## WCS Terminology Standards
- **WCS Events**: Use for gatherings and competitions (e.g., "WCS Events in California").
- **WSDC Registry**: Use when referring to rankings.
- **WSDC Database**: Use when referring to points.
- **WCS Event in [Location]**: Use for specific weekends.
- **Registry Standing**: Use for competitive progress.
- **Boom tick**: Use for rhythm reference (downbeat/upbeat).

## Dance Language
- Lead-Follow Communication
- Connection, Frame, Posture
- Counterbalance, Anchor, Whip
- Sugar Push, Left/Right Side Pass
- Momentum and Body Flight
- Connection Delay and Being Late
