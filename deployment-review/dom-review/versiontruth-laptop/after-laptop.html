VersionTruth

The antidote to version hallucinations: real-time ground-truth for npm, Node, and GitHub Actions. Exposes live, registry-fetched ground-truth so coding agents stop downgrading correct dependency versions.

The Fallacy

LLMs suffer from knowledge cutoff dates. When they encounter newer, unfamiliar releases (like v6), they confidently assume they are hallucinations or typos and revert them back to old, stale versions (like v4) that exist in their training data.

The Remedy

VersionTruth serves as a live oracle. Before writing updates, an agent queries the API or reads the hosted skill.md to verify that their candidate is current and valid.

API Endpoints

GET/api/latest-version?ecosystem={npm|node|gh-action}&name={name}

Retrieves the current latest stable version of a package or runtime.

Example Call
curl "https://boomtick.blog/api/latest-version?ecosystem=npm&name=pnpm"
GET/api/compare-version?ecosystem={npm|node|gh-action}&name={name}&candidate={version}

Verifies a candidate version against the latest release, warning if it is outdated, deprecated, or EOL.

Example Call
curl "https://boomtick.blog/api/compare-version?ecosystem=gh-action&name=actions/checkout&candidate=v4"
POST/api/batch-compare

Validates a list of dependency candidate versions concurrently in a single batch request.
