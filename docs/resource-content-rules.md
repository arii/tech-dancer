# BoomTick Resource Content Rules

## Gear
Use Gear for third-party product recommendations.
Gear items may include affiliate links.
Gear items should use affiliate disclosure where needed.
Gear files should not include boomtick.printful.me links.

## Merch
Use Merch for BoomTick-created Printful products.
Merch links are not affiliate links.
Merch items should use Printful/storefront language.
Merch items may be connected to events, Pride, NorCal, WCS roles, or dance themes.

## Resources
Use Resources as a discovery hub.
Do not duplicate full Gear or Merch catalogs on the Resources page.
Preview content and link to the dedicated page.

## Event Guides
Event guides may reference both Gear and Merch.
Do not duplicate product data inside event guide files.
Reference product IDs or slugs instead.
