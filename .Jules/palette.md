## 2024-05-18 - [ARIA labels on dynamic icons]\n**Learning:** The mobile menu toggle button (`Navigation.tsx`) had no accessible text, despite dynamically rendering different icons depending on its state. Added dynamic `aria-label` text to indicate state (Open menu vs Close menu). Also the email input box in the main view (`App.tsx`) was relying solely on `placeholder` text which is poor a11y, requiring an explicit `aria-label` for screen reader context.\n**Action:** When inspecting buttons with dynamic React state (e.g. `isOpen`), verify that any `aria-label` is also dynamically toggled to accurately reflect the action.
